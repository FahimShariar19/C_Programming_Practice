# C and C++ Programming Practice 🚀

Welcome to my repository for C and C++ programming! This repository serves as a personal archive for my daily coding practice, basic computer science fundamentals, and problem-solving journey using **Code::Blocks**.

## 📌 Features & Structure
- **Languages Used:** C (`.c`) and C++ (`.cpp`)
- **IDE:** Code::Blocks
- **Topics Covered:** Core Fundamentals, Control Flow, Functions, Arrays, and DSA concepts.

## 🛠️ Getting Started
To run any of the programs locally, you can follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Open the source file (`.c` or `.cpp`) in **Code::Blocks** or any modern C++ IDE.
3. Build and run the project (`F9` in Code::Blocks).

## 📂 Keeping It Clean
This repository is configured with a `.gitignore` file to ensure that compiled binary files (like `*.exe` and `*.o`) are automatically blocked, keeping the codebase clean and lightweight.
